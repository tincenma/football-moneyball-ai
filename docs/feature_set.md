# Moneyball 2.0: Feature Set v1.0.0

Зафиксирован 07.11.2026 после полного аудита предоставленных архивов. Машиночитаемый источник истины — [config/feature_set_v1.json](../config/feature_set_v1.json). Эмпирическое обоснование, размеры таблиц, схемы, потери при объединении и исторические ограничения — в [отчёте](data_profiling.md).

## Объект и дата

Одна строка — один мужчина-игрок FIFA 23 на **26.09.2022**, у которого точный токен `CM` присутствует среди позиций. `CAM`/`CDM` без `CM` не включаются. Основной CM — отдельный описательный поднабор, а не обязательный фильтр.

Для поиска сходства доступны **4 184** CM, из них **2 209** с основной позицией CM. Для модели записанной стоимости — **2 886** CM с надёжным автоматическим соответствием Transfermarkt и положительной оценкой не старше 365 дней на дату среза. Женские данные рассматриваются отдельно: в проверенных срезах связи с TM по выбранному правилу не найдены.

## X_similarity: 18 игровых характеристик

| Блок | Входы |
| --- | --- |
| Передачи | `attacking_short_passing`, `skill_long_passing`, `mentality_vision` |
| Владение | `skill_ball_control`, `skill_dribbling` |
| Подвижность | `movement_agility`, `movement_balance`, `movement_acceleration`, `movement_sprint_speed` |
| Реакция и самообладание | `movement_reactions`, `mentality_composure` |
| Физические характеристики | `power_stamina`, `power_strength`, `mentality_aggression` |
| Оборона | `mentality_interceptions`, `defending_marking_awareness`, `defending_standing_tackle` |
| Дальний удар | `power_long_shots` |

Все 18 заполнены у всех 4 184 CM выбранного среза. Использовать StandardScaler, обученный на тренировочной выборке CM, и фиксированные равные веса семи блоков: умножить каждый стандартизированный вход на `sqrt(1 / (7 * число_признаков_в_блоке))`. Ранжировать по cosine similarity. Нулевой вектор обрабатывать явно, сходство не интерпретировать как вероятность успеха.

Возраст и бюджет применяются как фильтры. `overall` используется только для сравнения с рейтинг-бейзлайном при тех же фильтрах. Цена, `potential`, репутация, клуб и лига в вектор сходства не входят.

## X_value: 27 исходных признаков

18 выше плюс:

| Тип | Входы | Получение / обработка |
| --- | --- | --- |
| Числовые | `age_at_cutoff`, `height_cm`, `weight_kg`, `weak_foot`, `league_level` | Возраст из `(cutoff - dob).days / 365.2425`; остальные из FIFA выбранного среза. |
| Категориальные | `preferred_foot`, `work_rate_attack`, `work_rate_defence`, `league_id` | Work rate разделить по `/`; league_id кодировать как категорию. |

`league_name` неоднозначен: одно название может относиться к нескольким чемпионатам. Поэтому контекст задаёт `league_id`; player_id и club_id входами не являются. На 2 886 целевых строках есть семь пропусков лиги: неизвестный ID → UNKNOWN, league_level → медиана тренировочной части. Категориальные входы one-hot encode с обработкой неизвестных значений. После кодирования размерность будет больше 27.

Извлекать X строго по allowlist контракта. Все преобразования, заполнение и кодирование обучать внутри train-fold. Не обучать scaler/encoder на holdout.

## Цель и служебные поля

Цель `target_log1p_tm_value = log1p(tm_market_value)`. Выбирается последняя запись истории оценок, у которой `market_value_date <= cutoff`. Дополнительно `tm_market_value > 0`, `0 <= market_value_age_days <= 365`. Не использовать ближайшую дату с любой стороны: она может оказаться в будущем.

`tm_market_value` — записанная оценка источника. В CSV TM нет валютной колонки, поэтому `_eur` не добавляется без подтверждения единиц. Это не transfer_fee, будущая результативность или доказательство «справедливой» цены.

В обучающем CSV 34 столбца: 27 входов, 2 формы цели и 5 служебных полей (`fifa_id`, `tm_id`, `fifa_update_date`, `market_value_date`, `market_value_age_days`). Служебные поля не включаются в X. Дата оценки и её давность нужны для аудита доступности и фильтра, а не как предикторы цены v1.

## Исключения

- `value_eur`, `wage_eur`, `release_clause_eur`, `value_at_transfer`, `transfer_fee`: денежные прокси, не входят в X.
- `overall`, `potential`, `international_reputation`: сводные оценки; overall оставлен для бейзлайна.
- Шесть агрегатов `pace`…`physic` и позиционные рейтинги `ls`…`gk`: не дублировать ими детальные 18 признаков.
- GK-атрибуты, clean_sheets, goals_conceded: не соответствуют CM-задаче.
- Текущие клуб, позиция, контракт, агент TM; cumulative national/teammate data: нет подтверждённого исторического состояния на 2022 год.
- Минуты/per-90, травмы, остаток контракта: не входят в обязательный v1. Полные минуты 21/22 доступны у 231 из 2 886 целевых CM, per-90 при ≥450 минут — у 186. Нет достаточной истории момента публикации и исправлений.
- xG/xA, progressive passes/carries, pressures, pass completion: отсутствуют в исходных схемах.

## История и проверка модели

Для неизменных 18 X годовые legacy-срезы пригодны начиная с **FIFA 17 / 20.09.2016**: в FIFA 15/16 отсутствует `mentality_composure`. Значение из будущего не переносить назад.

В одном срезе — групповой holdout по игрокам. В панели — хронологическое разбиение, отдельная проверка новых игроков и защита от попадания соседних обновлений того же игрока в train/test. Для ценовой задачи сравнивать с медианным предсказанием, оценивать ошибки на отложенных данных и устойчивость к порогу давности 180/365 дней. Для сходства сравнивать равные веса блоков с равными весами входов и рейтинг-бейзлайном.

v1 зафиксирован по содержанию и качеству данных. Обучение, подбор модели и абляционные эксперименты ещё не проводились. Высокое сходство на тех же X не является независимой проверкой успеха трансфера. Остаток ценовой модели — сигнал для дальнейшего изучения.
