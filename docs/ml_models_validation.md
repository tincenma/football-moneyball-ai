# Moneyball 2.0: проверка K-Means и KNN

Срез 2022-09-26. Fit: 2308 train-игроков; диагностика: 578 test-референсов.

## K-Means

k=3; train silhouette=0.170; test silhouette=0.169; медианный ARI при повторном fit на 80% train=0.863.

Группы алгоритмические и слабо разделены. Основной KNN не ограничивается кластером; ограничение включается явно.

## KNN

Oracle: 40/40 запросов с математически правильными расстояниями. Проверены бюджет, возраст, исторические даты и отсутствие self-match для всех 578 запросов.

Изменение среднего cosine против baseline: 0.804; это внутренняя целевая метрика, не независимое доказательство качества.

Для 41 дорогого референса изменение среднего cosine=0.115. В демонстрации T. Kroos только 0/5 строк TOP-5 проходят одновременно cosine ≥0,90 и RMS ≤0,75.

## Дополнительные диагностики

Без скрытого блока: среднее уменьшение RMS скрытых атрибутов против baseline=1.024; 95% paired reference CI [0.974, 1.076]. Положительный результат в 7/7 блоках.

При шуме σ=1 рейтинговый пункт средний overlap@5=79.8%; переключение кластера=1.4%.

Только дорогие референсы: уменьшение ошибки скрытых блоков=0.053; 95% CI [-0.038, 0.148]. Положительный результат в 4/7 блоках; универсальное превосходство не установлено.
